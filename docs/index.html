AT YOUR TABLE  /  本地开桌

用自己的电脑开个房间。

在开源仓根目录运行。首次安装需要联网，
组局时让手机与桌主连接同一局域网。

TERMINAL
npm ci
npm start

Node.js 22.13 或更新版本

  1. 桌主进入大厅

    打开终端显示的本机地址，输入昵称并创建房间。

  2. 朋友入座

    用手机打开终端显示的局域网地址，输入房间码。独自试玩可直接添加机器人。

  3. 把规矩说好

    在 UNO 房间展开村规，设置叠牌、换手和罚摸张数，再开始游戏。
